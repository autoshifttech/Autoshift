Meet Shifty

AutoShift’s cartoon mascot: a friendly WhatsApp-style chat bubble in brand green, with the logo’s double chevron as a little tuft. It shows up only at key moments (empty screens, AI thinking, wins and errors), never in tables or customer chats.

Build notes (for the app)

  • One component: <Shifty mood="happy" size={64} /> drawn as inline SVG with CSS animation, a few KB, no images, no libraries.
  • Colours come from theme tokens, so light and dark mode work automatically.
  • Decorative only (aria-hidden); the message next to it always carries the meaning.
  • All animation and eye-following stop with the system “Reduce motion” setting.
  • Users can switch it off in Settings → Appearance → Show mascot.
  • Never shown in tables, the admin panel, invoices or messages sent to customers.
